# 芋道任务下达与调整

复制下面一段，未知项可写“待查”，不要求一次填满。

涉及项目代码新增方法时，默认验收包含[新增方法注释约定](method-comments.md)：逐一核对每个新增方法的用途说明与实际行为。

```text
目标：
已知现状：当前分支/快照、可复现现象或现有行为
范围：允许改动的源码目录、环境与不涉及范围
受影响模块：后端 / 前端版本与仓库 / 数据库方言 / 其它
验收：用户可观察的结果与关键边界
验证方式：目标测试、构建、接口、浏览器或 SQL 演练
```

**调整原任务**时直接追加：`变更点：...；原因/新证据：...；取代的旧约定：...；新增或撤销的验收：...`。主任务保留已完成工作和证据；修改范围、权限、数据或兼容性发生实质变化时先明确决策。

示例：`目标：给 system 用户列表增加部门筛选；现状：项目版本为 2026.08-jdk25-SNAPSHOT；范围：system 后端及 Vue3 独立前端仓库；验收：授权用户按部门分页，越权不可查；验证：Service 测试、接口权限与真实 Vue3 页面。`
