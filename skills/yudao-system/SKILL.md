# 系统主数据

先确认本次项目版本、实际 Controller/VO、管理端 API 前缀及租户上下文。使用当前项目源码判断模块布局；参考核对样本为单体 `ruoyi-vue-pro`，不能套用来源 `yudao-cloud` 的 `-api/-server` 路径。

## 执行

1. 查询或配置主数据时，读[脚本使用与数据配置](references/workflow.md)。`scripts/system_creator.py` 提供查询和 JSON 配置预查；默认只读。令牌从 `YUDAO_TOKEN` 或受保护终端输入，租户由任务指定。
2. 先完成所有分页查询，再按角色 `code`、字典 `type/value`、菜单 `parentId + name` 核对现有记录。空结果只表示成功查询后没有数据；认证、权限、网络、响应结构或分页异常必须中止，不能触发创建。同名冲突或多个匹配需明确身份。
3. 创建须有针对目标环境和具体数据的任务授权，随后显式传 `--apply`（库调用 `apply=True`）。现有授权充分时直接继续；授权不充分时先完成只读预查，展示待建内容再取得缺失决策。导入技能、生成代码或持有令牌不构成业务写入授权。
4. 创建结果记录已有/新增 ID 与未完成操作。写入失败可能发生在服务端提交之后，先重查再决定补齐；不自动重试写入。工具不绑定管理员、不授予用户角色或菜单权限。核对样本中角色创建默认 `dataScope=ALL`，计划会显示这一服务端默认值。

## 按需参考

- 核对字段、权限、分页、菜单树、角色授权语义或来源中未实现的命令时，读[API 与菜单关系](references/api-reference.md)。角色/菜单授权是独立任务，`assign` 接口接收目标完整集合，不能当作追加操作。
- 追踪导入改写、版权范围和原文件 SHA-256 时，读[来源与适配记录](references/import-notes.md)及其清单。

脚本使用 Python 3.10+ 标准库，保持 TLS 校验并拒绝 HTTP 重定向。验证码按环境正常认证流程完成，不关闭验证码或安全校验。真实环境验收须分别验证 API 记录、权限关系和前端可见结果；本技能的隔离测试不能代替运行环境验收。
