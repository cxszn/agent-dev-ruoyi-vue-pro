# 来源与适配记录

此技能根据用户提供的 `yudao-skills_v1.1.0` 中 `yudao-system` 的主数据用途及相关说明进行适配。

原文件身份、相对路径、字节数和 SHA-256 记录在 [source-manifest.json](source-manifest.json)。该清单描述输入原件；不把本地磁盘绝对路径写入产物。当前核对源码的版本和相关文件摘要也在清单中，便于判断后续适配是否过期。

## 适配内容

- 保留角色/用户/部门/岗位/字典/菜单/租户的主数据查询用途，以及角色、字典、菜单先查后建流程。入口精简为执行规则，参数和 API/菜单关系按需加载。
- 来源 Python 文件经 AST 验证可解析；问题在于文档与函数/动作覆盖不一致、单页读取、查询失败转为空结果和部分不精确匹配。脚本重新实现为实例客户端，移除全局连接状态、固定账号密码示例、凭证 argv 和关闭验证码建议。
- 所有分页读完后才能判定缺失；异常中止。整批配置先校验、预查，再按 `--apply` 写入；精确身份冲突不转为创建。既有空字典和禁用项也能正确识别，失败批次输出已完成记录并要求重查。
- 显式传递任务的租户请求头，默认 TLS 校验，拒绝重定向；CLI 输出识别字段，错误正文不回显。新增测试使用标准库 mock，没有生产依赖。
- 以当前 `ruoyi-vue-pro` 单体源码核对字段、模块路径、菜单树与完整集合授权语义；不复制来源的 cloud 布局和前端固定版本。角色服务端默认 ALL 写入计划，创建不会顺带绑定管理员或授权菜单。
- 来源声明但未实现、或当前 system API 未提供的审批角色/分类字典等能力在 API 参考明确标为不支持。用户、部门、岗位仅查询；权限分配契约作为资料保留，未增加可执行权限写入工具。
- 未复制根文档内嵌图片、付费工具推荐、安装路径或无关宣传段落。库接口调整为 `SystemClient.query()` 与 `process_config()`，不声称兼容来源所有全局函数。

## 验证范围

`tests/test_system_skill.py` 在隔离 mock 下覆盖多页记录、查询/结构/认证失败、默认只读、apply 开关、精确复用、禁用字典项、批次部分失败、租户头与凭据保护。官方 `skill-creator/scripts/quick_validate.py` 用于检查技能结构。实际执行结果由本次任务报告给出；此说明不代替测试日志。

真实业务 API、数据库、容器、用户授权效果和前端页面均未运行验证。后续使用须以目标项目源码和任务授权为准。
