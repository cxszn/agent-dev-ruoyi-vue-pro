# 芋道模块与代码生成

先区分“使用生成器建立业务功能”和“修改生成器本身”，再读[生成流程与源码入口](references/workflow.md)。确定目标模块、数据库方言、表模型、前端变体和生成范围。

预览生成文件后再合并。已有业务文件逐项审查差异，生成的 SQL、菜单权限、错误码和前端路由仍需各自验收；生成器成功返回不证明业务可运行。

主子表核对关联字段与保存语义，树表核对父键与展示字段，移动端核对实际 UniApp工程及 WOT组件版本。模板类型与前端类型是两组独立选项。

修改模板时运行相关生成器回归，审查文件集合与语义；不得用重新生成全部断言文件来掩盖失败。模板覆盖范围、配置开关、真实测试证据和未运行项应出现在交付中。
