## 与当前源码的适用性变化

源码核验基线为 `2026.08-jdk25-SNAPSHOT`。各参考页使用仓库相对路径，结论来自源码和测试文件阅读；API、数据库与前端的运行验收仍需在目标项目中完成。

| 来源假设或冲突 | 本次采用的判断 |

| 所有模块拆 `*-api/*-server` | 当前 Boot 模块直接含 src；生成器通过 cloudEnable/getTemplates 适配两类布局。 |
| 移动端是第四种表类型 | 分为 templateType、frontType、scene、voType 四个独立维度，数值以当前枚举核验。 |
| 固定 Web/移动端依赖版本、请求参数与自动导入 | 当前快照缺完整前端依赖清单；模板可核验，运行项目需读其包与封装，版本不作为默认事实。 |
| 所有 API 与权限直接使用 businessName | 当前模板由 simpleClassName_strikeCase 生成接口/权限段；业务目录可以不同。 |
