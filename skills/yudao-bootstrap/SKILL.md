# 芋道启动与模块装配

涉及芋道项目代码新增方法时，遵守[新增方法注释约定](../../references/method-comments.md)，交付前逐一检查。

从当前任务的项目根目录工作，先读根 POM、BOM、服务 POM 和启动配置。目录名、历史技能和文档截图都不能代替这些文件的版本证据。按[启动与装配流程](references/workflow.md)定位本次需要的步骤。

- 启动失败：记录实际 JDK/Maven、激活 profile、第一条根因异常和相关配置键，避免直接套用其它分支启动命令。
- 启用模块：核对 Maven reactor、服务依赖、模块 API 依赖、数据库结构与运行组件，不能只取消根 POM 的一行注释。
- 改包或迁移模块：先列扫描包、包路径、POM坐标、配置占位符与跨模块调用，再按范围修改。
- 前端启动：先找到独立前端的 `package.json`、锁文件与 scripts；只有目录或 README 链接时，明确还缺可构建前端输入。

输出版本和模块证据、执行命令、实际启动结果及未验证项。首次初始化数据库、重启服务或使用已有部署环境，按当前任务授权与连接目标执行。
