# 芋道认证、授权与隔离

涉及芋道项目代码新增方法时，遵守[新增方法注释约定](../../references/method-comments.md)，交付前逐一检查。

按[安全链路与核验流程](references/workflow.md)追踪实际执行链。先定位登录身份，再分别检查接口权限、行级数据范围与租户范围；某一层通过不证明其它层正确。

菜单缺失沿角色菜单关联、权限信息返回、前端动态路由和按钮码核对；数据异常沿规则注册、当前身份与SQL过滤核对。不要通过全局放行、关闭租户或数据权限来消除局部错误。

选择能区分授权边界的验收：未登录、无角色权限、不同部门、不同租户及正常用户。涉及 app-api时核对用户类型与业务所有权，部门数据权限的管理端规则不能替代会员端所有权检查。

仅修改本次授权范围内的源码与配置。修改实际角色授予、租户开关或已有数据前，依据任务授权核对目标和影响。输出触发条件、链路证据、修复范围和真实验收结果。
